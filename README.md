## Running

```bash
cd hw3
pip install -r requirements.txt
python main.py
```

`main.py` loads IMDB, then runs `explore_mlp_structures`, `explore_mlp_activations`, and
`explore_mlp_learning_rates` in that order (14 training runs). The first run downloads IMDB and
`glove-twitter-50` (about 200 MB). On 2 CPU cores the whole script took about 25 minutes.

The runs reported in the PDF used Python 3.11, the CPU build of `torch==2.1.0`, and the pinned
versions in `requirements.txt`.

## Things that break on a current environment

1. `gensim==4.3.2` fails to import with SciPy 1.13 or later
   (`cannot import name 'triu' from 'scipy.linalg'`), so `requirements.txt` now pins
   `scipy==1.12.0`.
2. `torch==2.1.0` has no wheels for Python 3.12 or later. Use Python 3.10 (as `hw3.md` says) or 3.11.
3. The template's model and plot file names contain `" -> "`. Windows rejects `>` in file names,
   so `main.py` now writes `mlp_512-512_loss.png` instead of `mlp_512 -> 512_loss.png`.

## Changes outside the TODO blocks

- `mlp.py`: `SentimentClassifier` takes an `activation` argument (the assignment asks for it, but
  the class template's constructor had no such parameter), `run_mlp` passes it through, and the
  dataset shuffle is seeded (`seed=42`) so the splits are reproducible.
- `main.py`: the Canvas assignment asks for `explore_mlp_activations` and
  `explore_mlp_learning_rates`, which the class template does not contain. Their fixed
  hyper-parameters come from the upstream
  JHU CS 601.471/671 Sp24 hw3 skeleton: one 512-unit hidden layer in both, batch size 128 and
  learning rate 0.02 for the activation sweep, and batch size 64 with sigmoid for the learning
  rate sweep. Each experiment also saves its numbers to a JSON file.
- `mlp_lm.py`: `model.train()` at the start of each training epoch. `evaluate()` switches the
  model to eval mode, so without this line dropout would be off from the second epoch on.
  The fixed-window LM is not part of the Canvas assignment. Its TODOs are filled so the template
  has no open blanks, and it was checked with a forward and backward smoke test only.
  `sample_from_trained_mlp_lm` needs `pretrained_fixed_window_lm.dat`, which the template does
  not include.

## Results

Dev set 1,000 reviews, train 20,000, test 1,000. Best dev accuracy over 20 epochs:

| experiment | configurations | best dev accuracy |
|---|---|---|
| depth (sigmoid) | none, 512, 512-512, 512-512-512 | 0.771, 0.779, 0.777, 0.767 |
| activation (one 512 layer) | Sigmoid, Tanh, ReLU, GELU, LeakyReLU | 0.784, 0.774, 0.774, 0.787, 0.778 |
| learning rate (one 512 layer) | 0.1, 0.02, 0.002, 0.0002, 0.00002 | 0.772, 0.780, 0.769, 0.750, 0.694 |

The standard error of an accuracy near 77% on 1,000 reviews is about 1.3 points, so the depth
and activation differences are within noise. Discussion is in Section 6 of the PDF.
